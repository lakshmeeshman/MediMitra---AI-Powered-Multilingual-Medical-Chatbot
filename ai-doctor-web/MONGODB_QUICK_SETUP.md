# 🚀 MongoDB Quick Setup - 5 Minutes!

## ✅ **What You Need to Provide:**

Just **ONE** MongoDB connection string! That's it.

## 🔥 **Step 1: Create MongoDB Atlas Account (FREE)**

1. Go to [MongoDB Atlas](https://www.mongodb.com/cloud/atlas)
2. Click "Try Free" 
3. Sign up with Google/GitHub (no credit card needed)
4. Choose "M0 Sandbox" (FREE tier)
5. Select region closest to you
6. Create cluster (takes 3-5 minutes)

## 🔑 **Step 2: Get Your Connection String**

1. In Atlas dashboard → "Connect"
2. Choose "Connect your application"
3. Copy the connection string

**Example:**
```
mongodb+srv://username:password@cluster.mongodb.net/ai-doctor-db
```

## ⚙️ **Step 3: Update Your Environment**

Add this line to your `.env` file in the server folder:

```bash
MONGODB_URI=mongodb+srv://your_username:your_password@your_cluster.mongodb.net/ai-doctor-db
```

## 🎉 **That's It!**

Your app will now:
- ✅ Store medical reports in MongoDB (FREE)
- ✅ Save chat history in MongoDB (FREE)
- ✅ Work without any payment required
- ✅ Scale automatically
